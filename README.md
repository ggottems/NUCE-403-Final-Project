# NUCE-403-Final-Project
Final project of the NUCE 403 course. The objective is to create a reactor design and perform a neutronics analysis.

The specifications of the reactor are:
  1- D_{max} = 3 m.
  2- H_{max} = 5 m.
  3- Life cycle of a few years (5-8 years).
  4- etc...

Evaluations:
  1- Criticality: calculate the k_{eff} (cold zero power at BOL and EOL, hot full power at BOL and EOL);
  2- Temperature feedback: calculate the temperature reactivity feedback, a very important safety feature;
  3- Depletion: calculate how long does the reactor cycle is;
  4- etc...
